## 💎 Особенности проекта и дизайн-системы

1. **Anti-template & Anti-AI aesthetic**:
   - Авторская тёмная палитра Deep Obsidian (`#0B0D14`, `#121520`) с титановым текстом (`#F8F9FA`) и точечным люминесцентным акцентом Cyan/Teal (`#1EC1CB`).
   - Натуральный субпиксельный оверлей шума (grain).
   - Архитектурная типографика (`Golos Text` + `JetBrains Mono`).

2. **Интерактивные механики**:
   - **Hero Canvas Scroll Engine**: кинематографичный рендер 217 webp-кадров высокой чёткости при прокрутке экрана с моментальным показом 1-го кадра и плавным скрабом.
   - **Horizontal Pin-Scroll**: горизонтальный скролл-трек кейсов и концепций с прогресс-баром на десктопе и нативным touch-свайпом на смартфонах.
   - **Интерактивный бриф**: как в виде быстрого модального окна на главной странице, так и на отдельной автономной странице `brief.html`.
   - **Доступный FAQ-аккордеон** с плавными анимациями открытия.

3. **100% соответствие ТЗ**:
   - Прозрачный оффер: **35 000 ₽** под ключ, срок **до 14 дней**, поэтапная оплата **50% / 50%**.
   - Дополнительная опция фотосъёмки бизнеса в СПб (**+8 000 ₽**).
   - Секция «Сначала бизнес — потом сайт», фильтрация нецелевой аудитории, блок об авторе.

## 🚀 Инструкция по деплою на GitHub Pages

### Вариант 1. Через GitHub Actions (Рекомендуемый)
1. Создайте новый репозиторий на GitHub (например, `chumak-site`).
2. Инициализируйте git и запушьте файлы:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit premium website"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```
3. В настройках репозитория на GitHub перейдите в **Settings** → **Pages** → **Build and deployment** → в поле **Source** выберите **GitHub Actions**.
4. Сайт автоматически соберётся и опубликуется.

### Вариант 2. Деплой из ветки (Deploy from a branch)
1. В **Settings** → **Pages** выберите **Deploy from a branch**.
2. В выпадающем списке выберите ветку `main` и корневую папку `/ (root)`.
3. Нажмите **Save**.

## ⚙️ Настройка формы брифа и контактов

- Для отправки данных брифа в Telegram или на почту можно подключить любой Webhook (например, Make.com, n8n, Formspree или собственный PHP/NodeJS скрипт). В файле `assets/js/main.js` в секции `8. Модальное окно и интерактивный бриф` достаточно добавить `fetch('ВАШ_WEBHOOK_URL', { method: 'POST', body: ... })`.
- Ссылки на Telegram и VK настраиваются в `index.html` и `brief.html` поиском атрибутов `href="https://t.me/..."`.
